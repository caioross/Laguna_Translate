Configurar Discord com Laguna Translator (passo a passo)
  1. Instale VB-CABLE (grátis): https://vb-audio.com/Cable/ e reinicie.
  2. Abra Windows Sound Settings → Mais configurações de som.
  3. Em Gravação, clique direito em "CABLE Output" → Propriedades → aba Geral → renomeie para Laguna Translator Mic.
  4. Em Reprodução, clique direito em "CABLE Input" → Propriedades → renomeie para Laguna Translator Output.
  5. Clique em 🔄 Atualizar dispositivos no topo. Os devices aparecem marcados com 🌊.
  6. No Discord → Configurações → Voz e Vídeo:
    • Dispositivo de entrada: Laguna Translator Mic
    • Dispositivo de saída: escolha o fone real (não o virtual)
